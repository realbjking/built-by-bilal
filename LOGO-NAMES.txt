LOGO FILES (current)
====================
Each brand's logo lives in assets/brands/ under the name shown on the left. To change one, overwrite that file
(keep the same name; lowercase name and lowercase extension, e.g. aggc.jpg). If you switch format, delete the old file first.
Supported: png, webp, svg, jpg, jpeg. A brand page picks its colour from its logo automatically.

solicitors.png is still a placeholder: add the real logo as solicitors.png (or .jpg/.webp, deleting the placeholder).
